# Entrada de arquivos

Coloque aqui os materiais do projeto. A pasta é ignorada pelo git, exceto este arquivo.

Sugestão de organização:

```
_entrada/marca/          manual, logo, paleta, elementos gráficos
_entrada/fontes/         arquivos de fonte + licença
_entrada/referencias/    PDFs de capa, abertura, miolo, páginas especiais
_entrada/conteudo/       documentos, imagens, tabelas
```

A lista completa do que é necessário está em `docs/ENTRADA-DE-ARQUIVOS.md`.

Quando os arquivos estiverem aqui, avise o agente. Ele faz a triagem, atualiza a identidade e importa o conteúdo.
